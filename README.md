# FACELLI TECH (React + Vite)

## Instalar y correr
```
npm install
npm run dev
```

## Fotos
Poné las 24 fotos .webp (compu-1-a.webp ... compu-6-d.webp) dentro de la carpeta `public/`.
Con eso se ven solas en el catálogo y en cada ficha de producto.

## Build para producción
```
npm run build
```
Genera la carpeta `dist/` lista para subir a cualquier hosting.
